# シンプル ロジックツリー作成ツール

ブラウザ上で簡単にロジックツリーを作成できるツールです。
アイデアの整理、問題解決の可視化などに活用できます。

## 主な機能

-   ノードの追加、削除、編集
-   ノード間の親子関係設定 (自動レイアウト)
-   ノードへのテキスト設定
-   ノードへの画像表示 (URL指定)
-   ノードへの外部リンク設定
-   作成したロジックツリーのPNG形式でのエクスポート

## 開発・実行環境

-   モダンブラウザ (Chrome, Firefox, Edgeなど)
-   インターネット接続 (ライブラリをCDNから読み込むため)

## 基本的な使い方

1.  **`index.html` をブラウザで開きます。**

2.  **ノードの追加:**
    -   画面上部の「ノード追加」ボタンをクリックすると、新しいノードがツリーに追加されます。
    -   特定のノードを選択した状態で「ノード追加」ボタンをクリックすると、選択したノードの子として新しいノードが追加されます。
    -   ノードは自動的にレイアウトされます。

3.  **ノードの選択と削除:**
    -   ツリー上のノードをクリックすると、そのノードが選択されます（枠線が赤くなります）。
    -   ノードを選択した状態で、画面上部の「ノード削除」ボタンをクリックすると、選択したノード（およびそのノードに直接つながる線）が削除されます。

4.  **ノードの編集 (テキスト、画像URL、外部リンクURL):**
    -   編集したいノードをダブルクリックします。
    -   最初に、ノードに表示するテキストを入力するプロンプトが表示されます。
    -   次に、ノードの背景に表示する画像のURLを入力するプロンプトが表示されます（任意）。有効な画像URLを指定すると、ノードの背景にその画像が表示されます。不要な場合は空のままOKするか、キャンセルしてください。
    -   最後に、ノードに設定する外部リンクのURLを入力するプロンプトが表示されます（任意）。URLを設定すると、そのノードをクリックした際に新しいタブで指定されたURLが開きます。不要な場合は空のままOKするか、キャンセルしてください。

5.  **外部リンクの利用:**
    -   外部リンクURLが設定されたノードをクリックすると、新しいブラウザタブでそのURLが開きます。

6.  **ツリーのエクスポート:**
    -   画面上部の「エクスポート」ボタンをクリックします。
    -   現在のロジックツリーが `logic-tree.png` というファイル名でPNG画像としてダウンロードされます。

## 既知の制限事項

-   **エクスポートされたPNG画像にノードの背景画像が含まれない:**
    ノードに設定した背景画像（URLで指定したもの）は、エクスポートされたPNGファイルには表示されません。テキストやノードの形状、線は正しくエクスポートされます。
-   **ノード削除時の挙動:**
    ノードを削除すると、選択したノードとそのノードに直接接続されている線のみが削除されます。そのノードの子孫ノードが自動的にまとめて削除されるわけではありません。
-   **エラー処理の簡素化:**
    不正な画像URLや外部リンクURLが指定された場合の詳細なエラーハンドリングは行っていません。
-   **UIのシンプルさ:**
    編集操作はすべてブラウザ標準のプロンプトダイアログで行われます。より高度なUI（専用の編集フォームなど）は実装されていません。
